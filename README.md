## 🇸🇦 النسخة العربية

### 📖 نظرة عامة

نظام إدارة مدرسة المنار هو حل شامل ومتكامل لإدارة المؤسسات التعليمية، مصمم خصيصاً للمدارس العربية. يوفر النظام أدوات قوية لإدارة الطلاب والمالية والعمليات الإدارية بطريقة عصرية وسهلة الاستخدام.

### ✨ المميزات الرئيسية

#### 👥 إدارة الطلاب المتطورة
- ✅ **تسجيل الطلاب الذكي**: استخراج البيانات تلقائياً من الرقم القومي المصري
- ✅ **إدارة شاملة للملفات**: صور، وثائق، وبيانات شخصية كاملة
- ✅ **نظام المجموعات والفصول**: تنظيم مرن للطلاب حسب السنة والتخصص
- ✅ **تتبع الحضور والغياب**: نظام دقيق لمراقبة انتظام الطلاب
- ✅ **تقارير تفصيلية**: إحصائيات شاملة وتقارير قابلة للطباعة

#### 💰 نظام الخزينة المالية
- ✅ **إدارة الخزائن المتعددة**: دعم عدة خزائن مع أرصدة منفصلة
- ✅ **تتبع العمليات المالية**: سجل دقيق لجميع الإيرادات والمصروفات
- ✅ **تصنيف المصروفات**: تنظيم المصروفات بميزانيات شهرية
- ✅ **التقارير المالية**: تقارير مفصلة مع رسوم بيانية تفاعلية
- ✅ **نظام الاعتماد**: مراجعة واعتماد العمليات المالية

#### 🔐 نظام الصلاحيات المحسن
- ✅ **مستويات صلاحيات متدرجة**: من المشاهد إلى المدير العام
- ✅ **حماية البيانات**: تشفير وحماية متقدمة للمعلومات الحساسة
- ✅ **تسجيل العمليات**: سجل كامل لجميع العمليات والتغييرات
- ✅ **إدارة المستخدمين**: إضافة وإدارة حسابات الموظفين

#### 🎨 واجهة المستخدم العصرية
- ✅ **تصميم متجاوب**: يعمل على جميع الأجهزة (كمبيوتر، تابلت، هاتف)

## 🇺🇸 English Version

### 📖 Overview

Al-Manar School Management System is a comprehensive and integrated solution for managing educational institutions, designed specifically for Arabic schools. The system provides powerful tools for student management, financial operations, and administrative tasks with a modern and user-friendly interface.

### ✨ Key Features

#### 👥 Advanced Student Management
- ✅ **Smart Student Registration**: Automatic data extraction from Egyptian National ID
- ✅ **Comprehensive File Management**: Photos, documents, and complete personal data
- ✅ **Groups and Classes System**: Flexible organization by year and specialization
- ✅ **Attendance Tracking**: Accurate system for monitoring student regularity
- ✅ **Detailed Reports**: Comprehensive statistics and printable reports

#### 💰 Financial Treasury System
- ✅ **Multiple Treasury Management**: Support for multiple treasuries with separate balances
- ✅ **Financial Operations Tracking**: Accurate record of all revenues and expenses
- ✅ **Expense Classification**: Organize expenses with monthly budgets
- ✅ **Financial Reports**: Detailed reports with interactive charts
- ✅ **Approval System**: Review and approve financial operations

#### 🔐 Enhanced Permission System
- ✅ **Graduated Permission Levels**: From viewer to general manager
- ✅ **Data Protection**: Advanced encryption and protection for sensitive information
- ✅ **Operations Logging**: Complete record of all operations and changes
- ✅ **User Management**: Add and manage staff accounts

#### 🎨 Modern User Interface
- ✅ **Responsive Design**: Works on all devices (desktop, tablet, mobile)
- ✅ **User-Friendly**: Intuitive interface in Arabic
- ✅ **Multiple Themes**: Custom colors for each section
- ✅ **Visual Effects**: Animations and effects that enhance user experience

### 🛠️ Tech Stack

| Technology | Version | Description |
|-----------|---------|-------------|
| **Backend** | Django 5.2.6 | Main framework |
| **Language** | Python 3.13 | Programming language |
| **Database** | SQLite/PostgreSQL | Database system |
| **Frontend** | Bootstrap 5 | UI framework |
| **UI/UX** | HTML5, CSS3, JS | Web technologies |
| **Reports** | ReportLab, Openpyxl | Report generation |

### 📦 System Requirements

Python 3.11+
Django 5.2+
4GB RAM (minimum)
2GB storage space
Modern browser (Chrome, Firefox, Safari, Edge)
